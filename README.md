## Purpose

The purpose of this repository is to document my JavaScript learning journey through practical implementations rather than only theoretical exercises.

The projects gradually move from basic JavaScript concepts to working with APIs, asynchronous operations, browser storage, authentication, and small real-world applications.

## How to Run

Most projects are standalone `.html` files.

1. Clone the repository.
2. Open the required `.html` file in a browser.

For projects that use external APIs, an internet connection may be required and some APIs may require valid credentials or API keys.
